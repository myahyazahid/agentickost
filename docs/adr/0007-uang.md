# ADR 0007: Konvensi uang

- Status: diterima
- Tanggal: 26 September 2026
- Acuan: PRD §8.1, schema §1.3

## Keputusan

- Nominal disimpan sebagai `BIGINT` rupiah utuh di kolom berakhiran `_amount`. Tidak ada `FLOAT`, `DOUBLE`, atau `DECIMAL` untuk uang.
- Model memakai cast `App\Support\Money\RupiahCast` untuk kolom nominal. Cast menerima integer atau string angka bulat, dan melempar `InvalidArgumentException` untuk float (termasuk `440000.0`), desimal, atau teks berformat, sehingga float tidak pernah sampai ke database.
- Tampilan memakai `Rupiah::format()`: `Rp440.000`, negatif `-Rp25.000`.
- Perhitungan persentase dan pembulatan per properti (PRD §8.1) dibuat bersama mesin billing di M1.3.

## Konsekuensi

- Input dari form harus sudah berupa angka bulat sebelum masuk Action; validasi `integer` di Action tetap diperlukan agar pesan error ramah, cast hanya pengaman terakhir.
